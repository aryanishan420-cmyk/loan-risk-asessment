Key Technical Highlights for Academic Evaluation

  • Probability Calibration & Cost-Benefit Thresholding: Rather than arbitrary 0.5 threshold, an asymmetric loss threshold (FN cost = 4x FP cost) is derived, optimizing financial return and reducing default rates.
  • Relational Database Integration: Direct SQLite execution with pre-compiled views and automated logging of all prediction transactions for compliance audit trails.
  • Explainable AI (XAI): Each credit decision displays a factor attribution breakdown indicating specific strengths (e.g. low DTI, high FICO) and vulnerabilities (e.g. recent inquiries, delinquencies).
